## 2. "학교 인원 40명 이상" 활성화 조건이 실제로 걸려있는지

`accounts_user.group_id → accounts_group.school_id`로 학교별 실제 가입 유저 수를 집계하고, `polls_questionset.user_id`(질문 세트를 실제로 완료한 유저)를 학교 단위로 묶어 활동 여부와 교차 검증함.

### 결론: 조건은 걸려있으나, 기준은 "40명"이 아니라 **"딱 상위 10개 학교"**

- 전체 학교 5,951개 중 실제 가입 유저가 1명이라도 있는 학교는 5,551개.
- 이 중 `polls_questionset` 활동(투표 세트 완료 기록)이 **단 하나라도 존재하는 학교는 정확히 10개뿐**이고, 나머지 5,541개 학교는 예외 없이 활동이 0건.
- 이 10개 학교는 우연히도 **`accounts_school.student_count`(공식 학생수) 기준 전체 학교 중 정확히 상위 10위**와 100% 일치한다(483~578명 규모). 11위 학교(481명)부터는 활동이 전혀 없음.
- 즉 "가입 유저 수가 N명 이상이면 자동으로 활성화"라는 실시간 규칙이라기보다, **"미리 정해둔 상위 10개 대형 학교에만 투표 기능이 열려 있다"**는 형태에 훨씬 가까움. 굳이 숫자로 표현하면 컷오프는 "40명"이 아니라 **"약 483~486명(가입 유저 수) 이상"** 이었음 — 40명이라는 조건은 이 데이터에서는 확인되지 않음.
- 참고로 `accounts_school.student_count`와 실제 가입 유저 수(`reg_users`)는 전체 학교 평균으로 봐도 비율이 0.996(거의 1:1)이라, "공식 학생수"가 사실상 가입자 수를 그대로 반영하는 필드로 보임(독립적인 실제 재학생 수 데이터라기보단 가입 규모를 나타내는 파생값에 가까움).

## 3. 탈퇴 사유는 무엇인가

`accounts_userwithdraw`(70,764건, 전체 가입자의 10.5%)를 `reason` 기준으로 집계. ⚠️ 이 테이블엔 유저 식별 컬럼이 없어([table_notes.md](01_table_notes.md) 핵심 발견 2) 특정 유저·학교·활동 이력과 직접 연결은 불가능하고, 전체 분포/추이만 볼 수 있음.

| 탈퇴 사유 | 건수 | 비중 |
|---|---|---|
| 기타 이유 | 40,301 | 57.0% |
| 함께 할 친구가 없어서 | 14,450 | 20.4% |
| 재밌는 질문이 없어서 | 13,133 | 18.6% |
| 버그가 너무 많아서 | 2,031 | 2.9% |
| 구독료가 너무 비싸서 | 730 | 1.0% |
| admin | 61 | 0.1% |
| test | 53 | 0.1% |
| 기타 | 5 | 0.0% |

**해석**
- "기타 이유"가 57%로 압도적 1위라 실질적으로 유의미한 구체적 사유는 나머지 43% 안에서 봐야 함. 그 안에서는 **소셜(친구 부족) 20.4% > 콘텐츠 고갈(질문 없음) 18.6%** 순으로, 버그(2.9%)나 가격(1.0%)보다 "같이 할 사람/할거리 부족"이 압도적으로 큰 이탈 원인.
- `admin`(61건) / `test`(53건) 항목은 실제 유저 탈퇴가 아니라 내부 테스트/관리자 계정 정리로 보임 — 이탈률 계산 시 제외 권장.
- `기타 이유`와 `기타`가 별도 카테고리로 중복 존재(각각 40,301건 / 5건) — enum 값 정리가 안 된 데이터 이슈로 보임, 통합 필요.
- 탈퇴 시점 분포는 [table_notes.md](01_table_notes.md) 핵심 발견 5("2023-05 런칭 스파이크")와 동일한 패턴: 전체 탈퇴의 63%(44,845건)가 2023-05 한 달에 몰려 있는데, 같은 달 신규가입도 635,505명(전체 가입자의 93.9%)으로 폭증한 시점이라 "탈퇴만 급증"한 이상 신호가 아니라 **가입 볼륨 자체가 그 달에 쏠려 있어서 나타나는 비례적 현상**임(같은 달 가입자 대비 탈퇴 비율은 약 7.1%로 특별히 높지 않음).

- "40명 이상" 조건의 정확한 출처(기획 문서/코드) 확인 — 실제 데이터의 컷오프(약 483~486명, 상위 10개교)와 왜 다른지
- `polls_question`의 "vote" placeholder 56건이 실서비스 노출용인지 시드 데이터 버그인지 확인, 맞다면 통계에서 제외
- 탈퇴 사유 "기타 이유"(57%) 안에 더 세분화된 하위 사유나 자유 텍스트가 별도로 존재하는지(코드/기획 문서 확인) — 있다면 이탈 원인 분석의 진짜 핵심은 거기 있을 가능성
