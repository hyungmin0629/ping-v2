5. 이 판본이 남긴 것

확인된 것 — v4 로 그대로 이어진다

  • 봄학기형 성장 곡선이 설정과 ±0.5%p 안에서 재현된다
  • 인기도 49.3% · 민감 질문 신고 3.2배 · 완료율 두 측정 일치
  • 같은 반 친구 0~3명 15.9% · CLASS 스코프 33.5%
  • 투표 0회 유저가 사고가 아니라 설계로 만들어진다(5.8%)
  • 정합성 17종 위반 0 · 적재 2시간 2분(바이너리 읽기로 36분 단축)

남긴 교훈 — 같은 결함을 두 번 놓쳤다

시간대 균등을 user_session 에서 발견했는데, 고칠 때는 vote_session 만 봤다. 결함을 발견한 표와 고친 표가 달랐다.

같은 행동을 여러 표가 나눠 적는 구조에서는 한 곳을 고치고 다 고쳤다고 믿기 쉽다. 다음부터는 "이 행동을 적는 표가 또 있는가"를 먼저 묻는다.
