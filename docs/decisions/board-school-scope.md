# 게시판 범위는 학교, 카테고리는 하나

**결정** — `post.school_id` 는 클라이언트가 정하지 않고 RPC 가 글쓴이의 소속에서
끌어온다. 카테고리는 시드에 5개가 있지만 **자유게시판 하나만** 연다.

**이유** — 범위를 학교로 잡은 것은 스키마가 그렇게 설계돼 있어서이기도 하지만,
"누구와 같이 있는가"가 게시판의 전제이기 때문이다.
⚠️ 이때 `my_info_school_id()` 를 쓰면 안 된다. 그건 급식·시간표를 **어느 학교에서
빌려오는가**이고, 코드잇 DA 14기 사람이 서울고 게시판을 보게 된다.

카테고리를 하나로 둔 것은 규모 때문이다. 테스터가 20~50명인데 5개로 나누면
각 게시판이 텅 빈다. **빈 게시판은 아무도 쓰지 않는다.** 글이 쌓이는 걸 보고 쪼갠다.

**대안** — 반(class) 단위 게시판. 기각. 학교보다 더 작아서 같은 문제가 심해진다.

**영향** — 카테고리 코드는 `create_post` 의 인자로 남겨뒀다(기본값 `FREE`).
나중에 열 때 함수 시그니처를 바꾸지 않아도 된다.
