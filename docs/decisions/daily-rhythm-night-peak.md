# 하루 리듬을 붙인다 — 최대 봉우리는 점심이 아니라 밤 22시다

**결정** — 세션 시각에 **시간대·요일 가중치**를 건다. [Q23] 이 정한 "점심
12~13시 최대 봉우리"를 **밤 22~23시**로 바꾼다.

| 구간 | 평일 | 주말 |
|---|---|---|
| 00~06시 | 0.08~0.18 | 0.09~0.22 |
| 07~11시 | 0.32~0.38 | 0.30~0.45 |
| 12~13시 | 0.58~0.62 | 0.60~0.62 |
| 14~16시 | 0.28~0.32 | 0.60~0.62 |
| 17~21시 | 0.85~0.95 | 0.65~0.88 |
| **22~23시** | **0.98~1.00** | 0.85~0.90 |

**이유** — Q23 은 정해 놓고 **한 번도 구현되지 않았다.** v3 실측이 0~23시
전부 4.1~4.2%(완전 균등)였다. Q23 이 그 이유를 이렇게 적어 두었다 —
*"Looker 대시보드의 시간대 히트맵이 밋밋하면 시각화할 게 없다."*
지금 데이터로 히트맵을 그리면 정확히 그렇게 된다.

**Q23 의 모양을 뒤집은 이유** — 한국 학생은 점심시간에 폰을 오래 못 쓰고,
소셜 투표는 하교 후~취침 전에 몰린다. Q23 의 점심 봉우리는 "일반적인 앱"의
패턴을 가져온 것으로 보인다. 주말은 낮(14~16시)이 살아나고 밤 봉우리가
완만해지도록 따로 뒀다.

## ⚠️ 전원이 같은 곡선을 따르면 안 된다

페르소나와 같은 이유다([[user-personas]]) — 모두가 22시에 몰리면
**"심야형 유저"라는 분석 대상이 사라진다.**

| 유형 | 비중 | 봉우리 |
|---|---|---|
| 일반형 | 65% | 위 곡선 그대로 |
| 야행성 | 15% | 3시간 뒤로 (22시 → 01시) |
| 아침형 | 10% | 6시간 앞으로 (22시 → 16시) |
| 종일형 | 10% | 평평 — 시간 구분이 약하다 |

여기에 **혼합**(두 유형 6:4, 12%) · **무배정**(순수 무작위, 4%) ·
**개인 편차**(봉우리가 ±1.5시간 흔들림)를 겹친다.

**대안** — 시간대를 세션 수가 아니라 시각만 바꾸는 데 쓰는 안(기각 표집)을
검토했다. **재시도를 넣으면 안 된다** — 12번 재시도했더니 수용률이 50% → 97%
가 되어 계절성 솎아내기가 무력해지고 세션이 56% 불었다. 대신 **미리 부풀린다**
(`n_draw = w_n × boost / hour_mean`) — 솎아낼 만큼 더 뽑고 한 번만 판정한다.

**영향**

- 평일 최고 22시 **7.2%** · 최저 4시 **1.5%** — 5배 차이.
- 주말은 낮이 살아나고 밤이 완만해진다.

## ⚠️ 두 표에 각각 걸어야 한다 — 한 번 놓쳤다

리듬을 `gen_votes()` 에만 걸어서 **투표 세션에만** 적용됐다.
접속 세션(`user_session`)은 다른 함수에서 만들어지고 거기서는 하루 중
아무 분이나 균등하게 뽑고 있었다(`randint(0, 1439)`).

| 구간 | `vote_session` | `user_session` (고치기 전) |
|---|---|---|
| 시험기간 | 47% | **92%** |
| 겨울방학 | 23% | **56%** |
| 시간대 | 22시 최고 | **전부 4.14~4.21%** |

⚠️ **처음 감사에서 시간대 균등을 발견한 것도 `user_session` 이었다.**
고칠 때 `vote_session` 만 보고 같은 결함을 한 번 더 놓쳤다.
**"언제 앱을 여는가"를 묻는 가장 자연스러운 표가 그쪽이다.**

**교훈** — 같은 행동을 여러 표가 나눠 적는 구조에서는 **한 곳을 고치고
다 고쳤다고 믿기 쉽다.** "이 행동을 적는 표가 또 있는가"를 먼저 묻는다.

고친 뒤 실측 — 접속 세션 22시 7.79% / 4시 1.38%(5.6배),
시험기간 30% · 겨울방학 18%.

## ⚠️ 저장은 UTC, 패턴은 KST

시각은 UTC 로 저장된다(Q27). 그대로 집계하면 봉우리가 **9시간 밀려**
22시가 13시로 보인다. 감사 중에 실제로 그렇게 보였다.
Q27 이 이렇게 적어 뒀다 — *"Looker에서 '점심에 투표가 몰린다'가
새벽 3시로 보인다."*

`SET TIME ZONE 'Asia/Seoul'` 또는 `AT TIME ZONE` 을 먼저 건다.
- ⚠️ 설정을 `behavior` 라는 **새 절**로 만들었는데 `load_config` 가 옮기지
  않아 처음엔 통째로 사라졌다. 그래서 **절 목록을 손으로 나열하는 방식을
  뒤집었다** — 개별 처리한 절만 빼고 나머지는 전부 옮긴다. 같은 함정이
  2026-08-03~04 에만 네 번 반복됐다.
