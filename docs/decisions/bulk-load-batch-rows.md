# 합성 대량 적재는 배치를 20만 행으로 키운다

**결정** — `extract_load.py` 에 `--batch-rows` 를 열었다. 기본값은 5만 그대로고,
합성 데이터(`--source local`) 전량 적재에서만 **20만**을 쓴다.

**이유** — 속도가 아니라 **적재 작업 수**다.

BigQuery 는 **테이블당 하루 1,500건**의 적재 작업만 받는다. v5 는 1억 2,370만 행이고
`vote_candidate` 하나가 6,708만 행이라, 5만씩 끊으면 그 표에서만 **1,342건**이 나온다.
한도 아래이긴 하나 여유가 158건뿐이라 **중간에 한 번 실패하면 그날은 다시 못 돌린다.**
20만이면 336건이라 재시도가 몇 번이든 가능하다.

속도는 덤이다. `user_session` 987,624행으로 같은 조건에서 재봤다 —
**5만 배치 171초 · 20만 배치 110초**로 1.55배. 배치당 고정 왕복 비용이
실제 전송보다 컸다는 뜻이다. 전체 추정이 6시간에서 3~4시간으로 내려간다.

**대안**
- *5만을 유지하고 그냥 돌린다* — 기각. 한도에 158건 여유는 재시도를 못 견딘다.
- *더 키운다(40만 이상)* — 기각. 5만→20만의 이득(1.55배)에서 더 짜낼 것이 적고,
  한 덩어리가 통째로 메모리에 올라가므로 6,708만 행짜리 표에서 위험만 커진다.
- *CSV 를 BigQuery 에 직접 올린다* — 기각. 업로드 용량은 훨씬 유리하지만
  (JSON 은 열 이름을 행마다 반복해 CSV 의 3~4배가 된다) 파이프라인을 우회하게 된다.
  `pgtest` 에 v5 가 이미 적재돼 있어 원천이 살아 있었으므로 우회할 이유가 없었다.
  **수십 GB 급이 되면 이 대안을 다시 본다** — [[bigquery-direct-no-gcs]] 가
  같은 조건을 재검토 시점으로 적어 뒀다.

**영향**
- [[bigquery-direct-no-gcs]] 의 "배치(5만 행)"은 이제 **기본값**이라는 뜻이다.
  실유저 증분은 한 번에 수백 행이라 배치 크기가 애초에 무의미하고, 기본값을
  건드리지 않은 것은 그래서다.
- 같은 노드가 "raw 전체가 450MB" 를 직접 업로드의 근거로 들었다. 이 적재로
  **약 11GB** 가 된다. 저장 무료 한도(10GiB)를 넘지만 초과분은 월 0.1달러 미만이라
  판단을 뒤집지 않는다. 다만 **다음 증설 때는 GCS 경유를 다시 계산해야 한다.**
- 재시도 방법이 달라진다. 실패한 표는 워터마크가 안 찍히므로 `--full-refresh`
  **없이** 다시 돌리면 된다 — 끝난 표는 증분으로 0행 처리되고 실패한 표만
  전체 경로를 탄다(전체 경로는 `_source='local'` 을 먼저 지우므로 중복이 안 남는다).

**정정 (2026-08-06, 같은 날)** — **막은 것은 여기 적은 한도가 아니었다.**

이 결정대로 20만 배치로 전량 적재를 돌렸더니 `vote_candidate` 2,620만 행에서
`403 Quota exceeded: Number of partition modifications to a column partitioned
table` 이 났다. 실제로 걸린 것은 적재 작업 수(1,500건)가 아니라 **파티션 수정
횟수(테이블당 하루 4,000회)** 였고, **배치를 키운 것은 이 한도에 아무 도움이
되지 않았다.** 오히려 무관했다.

결정 자체(`--batch-rows` 를 열고 20만을 쓴다)는 유지한다. 속도 이득 1.55배는
실측대로였고 부작용이 없었다. 다만 **"한도 때문에 안전해졌다"는 근거는 틀렸다** —
안전은 [[partition-ordered-extract]] 가 만들었다. 여기 적힌 1,500건 계산을
근거로 다른 판단을 하지 말 것.

**교훈** — 한도에 걸릴 것 같으면 **어느 한도인지 이름으로 확인한다.**
BigQuery 의 적재 관련 한도는 여러 개고 서로 다른 것을 센다. 그럴듯한 하나를
골라 대비하면 대비한 기분만 남는다.

## 이어지는 결정

  — 실제로 막은 한도를 푼 결정. 이 노드의 근거를 정정한다
