# 신고와 제재를 FK로 연결하고 정책을 데이터로 정의

**결정** — `sanction.triggered_by_report_id`로 근거 신고를 명시하고, `sanction_policy` 테이블에
자동 제재 임계값을 저장한다.

**이유** — 기존 시스템은 신고와 제재가 완전히 단절돼 있었다. 피신고 10회 이상 116명 중 제재된 사람이
0명이고, 253회 신고받은 유저도 정상 상태로 활동 중이었다. 임계값이 코드에만 있으면(혹은 없으면)
운영 정책을 감사할 수 없다.

**영향** — "몇 회 신고 시 어떤 조치"가 스키마에 드러난다. 다만 **정책이 있어도 검토할 사람이 없으면
의미 없다** — 그래서 익명 게시판을 v1에서 뺐다.
