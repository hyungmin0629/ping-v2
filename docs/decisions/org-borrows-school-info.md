# 테스트 조직은 이름을 유지하고 실제 학교의 정보를 빌려 쓴다

**결정** — 클로즈드 테스트 조직의 표시명은 "코드잇 DA 14기"로 두고,
급식·시간표·학사일정은 **서울고등학교**(표준학교코드 7010083)의 공개 데이터를 쓴다.
학급도 서울고의 2026학년도 실제 학급(1~3학년 × 1~14반)을 그대로 넣었다.

**이유** — 임시 조직에는 급식도 시간표도 없어서 W8 화면을 시험할 수 없다.
그렇다고 이름을 실제 학교로 바꾸면 테스터에게 낯설고, 앞서 계획했던 "임시 조직을
지우고 계정을 옮기는" 작업도 필요해진다. 표시명과 정보 출처를 분리하면 둘 다 없어진다.

**대안** — 조직 행의 `neis_school_code` 에 서울고 코드를 직접 넣기. 기각.
그 컬럼은 UNIQUE 라 서울고 행과 충돌하고, 학교 목록을 다시 받을 때
`ON CONFLICT` 가 조직 이름을 "서울고등학교"로 덮어쓴다.
→ `school.info_school_id` 를 추가해 가리키게 했다(migration 002).

**영향**
- 기존 1~4팀은 서울고 학급과 `(grade=1, class_num=1~4)` 가 겹쳐서 그대로 흡수됐다.
  3팀이던 계정들은 **1학년 3반**이 됐다. 계정 이전 작업이 없었다.
- 온보딩이 학년·반 두 단계로 바뀌었다. 반이 14개까지 있어 한 목록으로는 길다.
- 테스터에게 "1팀이면 1학년 1반"이라고 화면에서 안내한다.
- ⚠️ 보이는 급식·시간표는 **실제 서울고 학생들의 것**이다. W8 화면에
  출처를 밝히는 문구를 넣는다. 공개 데이터지만 "우리 반 시간표"로 읽히면 사실과 다르다.
- ⚠️ 분석할 때 이 조직은 실제 학교처럼 섞인다. `is_synthetic` 은 유저에만 있고
  학교에는 없다. P6 에서 학교별 지표를 만들 때 이 id(4)를 알고 있어야 한다.
