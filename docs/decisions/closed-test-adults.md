# 성인 지인 대상 클로즈드 테스트로 한정

**결정** — 링크를 아는 성인 지인 20~50명만 사용. 불특정 다수 공개 안 함.

**이유** — 원 서비스는 중·고등학생 대상이었다. 미성년자 데이터는 만 14세 미만 법정대리인 동의가
필요하고, 외모 관련 투표와 익명 게시판을 미성년자에게 열면서 모니터링이 없으면 감당할 수 없다.
성인 지인으로 한정하면 동의 취득이 실질적으로 가능하고 사고 위험이 크게 준다.

**영향** — 실유저 데이터 규모가 작다(수천 행). 그래서 파이프라인 학습용 합성 데이터가 별도로 필요해졌다.
