# `GLOBAL` 스코프는 "내 친구 전체"

**결정** — 세 스코프의 후보 풀을 이렇게 정의한다.
`CLASS` = 같은 반 친구 / `SCHOOL` = 같은 학교 친구 / `GLOBAL` = 학교 무관 친구 전체.
**세 스코프 모두 친구 관계가 전제**이며, 모르는 사람은 어떤 경우에도 후보로 뜨지 않는다.

**이유** — 기존 서비스 데이터에서 후보의 98.5%가 실제로 투표자의 친구였다(친구 풀에서 뽑는 구조였음).
그리고 차단 사유 1위가 "모르는 사람임"(49.5%)이었다. 전체 가입자를 후보로 넣으면
모르는 사람이 뜨고 차단·신고가 늘어난다.

**대안** — `GLOBAL`을 전체 가입자로 정의. 기각. 위 이유에 더해, 모르는 사람에 대한 투표는
서비스 취지(아는 사이의 가벼운 인정)와 맞지 않는다.

**영향** — 친구 5명 게이트가 후보 풀의 하한을 보장한다.
합성 데이터 생성 시 친구 그래프를 먼저 만들고 그 위에서 후보를 뽑아야 한다(생성 순서 제약).
