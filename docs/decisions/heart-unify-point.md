# 하트와 포인트를 하나로 통합

**결정** — 두 개의 통화를 두지 않고 `user.heart_balance` 하나로 관리한다.

**이유** — 기존 DB에서 이미 사실상 같은 것이었다. `accounts_user.point` 컬럼과 핵클의
`heart_balance`가 같은 유저에서 값이 일치했다(user 833041: 885,000,006 vs 884,999,804).
UI는 "하트"라 부르고 DB 컬럼명은 `point`여서 분석할 때마다 혼선이 있었다.

**대안** — 포인트(적립 전용)와 하트(구매 전용)를 분리. 기각한 이유는 실제 사용처가
구분되지 않아 분리해도 두 잔액이 같이 움직일 뿐이었기 때문.

**영향** — `heart_transaction` 하나가 모든 증감을 기록한다. 적립·차감·충전·광고보상이 전부 여기 모인다.
