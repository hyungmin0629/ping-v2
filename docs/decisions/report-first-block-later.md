# 신고는 게시판과 함께, 차단은 뒤로

**결정** — 글·댓글 신고를 게시판과 같이 냈다. 차단(`block_record`)은 만들지 않았다.

**이유** — "게시판을 열기 전에 차단·신고 화면이 먼저"라고 적어뒀지만, 둘의 급함이
다르다. **게시판은 공개 공간이라 "안 보이게"보다 "내려가게"가 먼저 필요하다.**
차단은 상대가 나에게 직접 말을 걸 수 있을 때 — 즉 1:1 메시지가 생길 때 — 값이 생긴다.

**대안** — 차단까지 다 만들고 게시판을 연다. 기각하지 않고 **순서만 바꿨다.**
남은 두 기능(익명 메시지·채팅방) 전에는 차단이 있어야 한다.

**영향**
- 신고해도 **자동으로 내려가지 않는다.** 자동 숨김은 집단 신고에 취약해 진작에
  기각한 방식이다. 기록만 남고 사람이 판단한다 — 검토 인력이 없는 상태로 여는
  것이므로, 작업자가 `report` 테이블을 직접 봐야 한다.
- 같은 사람이 같은 대상을 여러 번 신고해도 한 건으로 센다. 안 막으면 한 사람이
  `report_count` 를 얼마든지 올릴 수 있다.
- 글 삭제는 행을 지우지 않고 `status = 'DELETED'` 로 둔다.
  `report.target_post_id` 가 FK 라 지우면 신고 기록이 가리킬 대상이 사라진다.
  **사고가 난 글일수록 지워지면 안 된다.**
