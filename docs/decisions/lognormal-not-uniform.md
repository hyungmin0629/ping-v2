# 시간 간격을 균등분포에서 로그정규로 바꾼다 — v5

**결정** — 체류시간·응답속도·열람지연 등 **모든 시간 간격**을 `rng.randint(lo, hi)` 대신
`lognormal_span()` 으로 뽑는다. 짧은 쪽이 두껍고 긴 꼬리가 붙는다.

**이유** — v4 는 시간 간격이 **전부 균등분포**였다. 균등도(실측 stddev ÷ 같은 범위
균등분포의 stddev)가 6종에서 **1.0 근처**로 나왔다 — 완전한 균등이라는 뜻이다.

오류가 안 나고 정합성 검사도 통과하지만 **분포 형태 분석이 통째로 불가능**했다.
"체류가 길수록 많이 투표한다" 같은 가설은 **검정 자체가 안 됐다** — 길이가 무작위라
어떤 것과도 상관이 없기 때문이다.

**⚠️ 상한을 넘으면 자르지 않고 다시 뽑는다.** 잘라서 `hi` 로 만들면 상한에 값이 뭉쳐
히스토그램에 벽이 생긴다. 8번까지 다시 뽑고 그래도 안 되면 균등으로 물러선다(1% 미만).

**대안** — 지수분포를 기각했다. 봉우리가 0에 붙어 "가장 흔한 체류시간"이 사라진다.
로그정규는 봉우리 위치(`peak`)와 꼬리 두께(`sigma`)를 따로 조절할 수 있다.

## 영향

| 간격 | v4 균등도 | v5 균등도 | v5 중앙값 |
|---|---|---|---|
| 접속 세션 길이 | 1.042 | **0.154** | 10.4분 (최대 717.7분) |
| 친구요청 응답 | 0.683 | **0.327** | 3.9시간 |
| 받은투표 열람 지연 | 1.014 | **0.431** | 4.5시간 |
| 투표 세션 길이 | 1.054 | **0.471** | 6.5분 |
| 문항 응답 | 1.045 | **0.535** | 12.5초 |
| ⚠️ 광고 시청 | 1.006 | **1.005** | — 빠뜨렸다 |

- 접속 세션 길이 변동계수가 0.5128 → **1.5406** 으로 올랐다. p99 가 25분(균등의 상한)에서
  **161.9분**으로 바뀌었다 — 이제 분위수가 의미를 갖는다
- **광고 시청 시간 한 곳을 빠뜨렸다.** 7곳을 바꾸면서 `ad_impression` 만 남았다.
  생성기 1줄이고 다음 판본에서 고친다
