# 힌트를 골라 사게 바꾼다 — 순차 4단계 폐기

**결정** — 힌트를 순차 4단계(성별 200 → 초성 300 → 반 500 → 공개 1000)에서
**선택형 5+1** 로 바꿨다. 기본 5종(성별·초성·중성·종성·반)은 각 20하트이고
**순서가 없다.** 이름 공개는 100하트이며 기본 5종 중 3개 이상을 연 뒤에만 산다.

**이유** — 누진 요금은 구 서비스 실측이었지만 두 가지가 걸렸다.
값이 커서(합계 2,000하트) 실제로 끝까지 사는 사람이 없었고, 순서가 고정이라
"성별은 궁금하지 않은데 반이 궁금한" 사람이 200하트를 버려야 했다.

값을 20으로 낮추고 순서를 없애면 **여러 사람의 힌트를 조금씩 사는 쪽**이
가능해진다. 하트 소비가 한 건에 몰리지 않고 흩어지므로, 무엇이 궁금한지가
데이터로 드러난다 — 지금 구조로는 "성별부터 산다"밖에 관찰되지 않았다.

**대안** — 값만 낮추고 순서는 유지. 기각. 순서가 남으면 "무엇을 먼저 사는가"를
여전히 못 본다.

**영향**
- 자모 힌트(초·중·종성)는 **각자 다른 글자**를 연다. 한 글자로 묶으면 세 번을
  사도 한 글자짜리 정보가 된다.
- 종성 힌트는 **받침이 있는 글자를 먼저 고른다.** 아무 글자나 뽑으면
  "받침 없음"만 나오는 일이 잦아 20하트값을 못 한다.
- 자모 계산은 DB 가 한다(`db/rls/hangul.sql`). 화면에서 하면 아직 안 산 자모가
  브라우저로 나가고, 보낸 뒤 숨기는 것은 가린 것이 아니다.
- 성별은 **광고 30초로도** 열 수 있다(하루 한 번). 광고는 스텁이지만 기록은
  진짜로 남긴다 — "광고를 보고 여는 사람이 얼마나 되나"가 넣은 이유다.
- 옛 순차 힌트로 산 INITIAL 19건은 `char_index` 가 없어 아무것도 안 보였다.
  지금 규칙으로 자리를 정해 메웠다 — 300하트를 낸 사람이 빈손이 되면 안 된다.
