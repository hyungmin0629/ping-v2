# 마트 굽기를 별도 DAG 로 떼고 센서로 잇는다

**결정** — [[ops-p5-p7]] 의 "매번 도는 네 줄" 중 ③④(품질 검증 · 마트 굽기)를
**새 DAG `ping_mart_build`** 로 만든다. 기존 `ping_raw_load`(①②)는 **한 글자도
고치지 않고**, 새 DAG 쪽에서 `ExternalTaskSensor` 로 앞 DAG 의 `verify` 태스크가
성공하기를 기다린다.

**이유**

- **적재는 마트가 없어도 혼자 의미가 있는 일이다.** `ping_raw_load` 에 outlet 이나
  `TriggerDagRunOperator` 를 달면 두 DAG 가 서로를 알아야 한다. 센서는 한쪽에서만
  아는 관계라 앞 DAG 는 뒤에 무엇이 붙었는지 몰라도 된다.
- **실패 지점이 갈린다.** "적재가 멈춘 것"과 "마트가 안 구워진 것"이 다른 DAG 의
  다른 실패로 보인다. 한 DAG 에 여섯 태스크를 이으면 화면에서 둘을 구분하려고
  매번 태스크 이름을 읽어야 한다.
- **재실행 단위가 다르다.** 마트 SQL 을 고쳐 다시 굽고 싶을 때, 적재까지 딸려
  도는 것을 막으려면 결국 태스크를 골라 지워야 한다. DAG 가 나뉘어 있으면
  뒤엣것만 트리거하면 된다.

**스케줄을 같은 크론(`0 4 * * *`)으로 맞췄다.** `ExternalTaskSensor` 는
**논리적 날짜(logical date)** 로 짝을 찾는다. 두 DAG 의 스케줄이 어긋나면
`execution_delta` 를 손으로 계산해 넣어야 하고, 한쪽 크론을 바꾸는 순간 조용히
짝을 잃는다. 같은 크론이면 그 계산 자체가 없다.

**손으로 트리거한 실행은 기다리지 않는다.** 합성(local)을 다시 구울 때는 그날
`ping_raw_load` 가 돌았을 이유가 없다. 기다리게 두면 짝이 없는 논리적 날짜를
붙들고 타임아웃까지 간다. `BranchPythonOperator` 가 `run_type == "manual"` 이면
센서를 건너뛴다.

**품질 검증이 깨지면 마트를 굽지 않는다.** 대시보드가 **옛 숫자**를 보여주는 것이
**틀린 숫자**를 보여주는 것보다 낫다. 마트는 `CREATE OR REPLACE` 라 굽기 전까지
지난번 표가 그대로 살아 있다.

**대안**

- **`ping_raw_load` 에 태스크 두 개를 덧붙이기** — 기각. 이름이 거짓말이 되고
  (`raw_load` 가 마트를 굽는다), 재실행 단위가 뭉친다
- **Dataset 스케줄링**(Airflow 2.4+) — 기각. 앞 DAG 에 `outlets=` 를 달아야 해서
  "고치지 않는다"는 전제와 부딪힌다. 앞 DAG 를 손댈 일이 생기면 그때 옮긴다
- **한 시간 뒤(05:00)에 독립 스케줄** — 기각. 적재가 실패해도 마트가 그대로 구워져
  **대시보드가 멀쩡해 보인다.** 2026-08-18 에 12일 멈춰 있던 것을 아무도 모른
  실패 방식이 정확히 이것이다
- **`--yes` 로 스캔량 상한 무시** — 기각. 상한을 넘으면 조용히 돈이 나가는 대신
  태스크가 실패해서 눈에 띄어야 한다

**영향**

- `airflow/dags/ping_mart_build.py` 하나가 늘었다. `ping_raw_load.py` 는 그대로다
- `stg` 는 굽지 않는다 — 뷰라서 ①이 끝나면 이미 최신이다.
  `bigquery/staging/*.sql` 을 고쳤을 때만 손으로 `--layer stg`
- 원천은 파라미터(`source`)다. 기본 `supabase` 가 매일 돌고,
  `local` 은 합성을 재생성했을 때만 손으로 트리거한다
- ⚠️ **하루 스캔이 19 GiB 다**(품질 11.7 + 마트 7.3, 2026-08-20 실측).
  매일 돌리면 월 570 GiB — **쿼리 무료 한도 1 TiB 의 56%**. 팀원 4명의 애드혹
  쿼리가 같은 한도를 나눠 쓰므로 여유가 많지 않다. 줄여야 하면 **품질 검증을
  주 1회로 내리는 것이 먼저다** — 마트를 굽는 7.3 GiB 는 신선도와 직결되지만
  품질 검증 11.7 GiB 는 그렇지 않다
