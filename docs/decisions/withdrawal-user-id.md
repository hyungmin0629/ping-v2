# 탈퇴 기록에 유저 식별자를 넣는다

**결정** — `user_withdrawal.user_id`를 NOT NULL FK로 두고, 자유 서술 `reason_text`도 받는다.

**이유** — 기존 `accounts_userwithdraw`는 70,764건(가입자의 10.5%)인데 `reason`과 `created_at`뿐이라
누가 탈퇴했는지 특정할 수 없었다. 탈퇴 사유를 유저 속성과 교차분석하는 게 원천 봉쇄됐다.
게다가 사유의 57%가 "기타 이유"라 실질 정보가 거의 없었다.

**대안** — 개인정보 보호를 위해 익명 유지. 기각. 탈퇴자 데이터는 보관 기간을 짧게 두고
파기하는 방식으로 관리하면 되고, 분석 불가능한 데이터를 쌓는 것보다 낫다.

**영향** — 탈퇴 사유별 코호트 분석이 가능해진다. `reason_text`로 "기타" 블랙박스를 연다.
