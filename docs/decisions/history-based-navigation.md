# 화면 이동을 브라우저 이력에 싣는다

**결정** — 화면을 바꿀 때 `history.pushState` 로 한 칸 쌓고, `popstate` 에서
홈으로 되돌린다. 화면 안의 닫기 버튼도 `history.back()` 을 거친다.

**이유** — 이 앱은 주소를 나누지 않고 상태로 화면을 가른다(동적 라우트를 쓸 수
없는 사정은 [[CLAUDE]]). 그대로 두면 **휴대폰 뒤로가기가 앱을 나가버린다.**
테스터 대부분이 폰으로 들어오므로 실제로 자주 밟는 자리다.

**대안** — 화면마다 주소를 준다. 기각. 이 환경의 개발 서버가 동적 라우트를
열지 못해 로컬에서 확인할 수 없다. 확인할 수 없는 화면은 만들지 않는다.

**영향** — 닫기 버튼이 `setScreen("home")` 이 아니라 `history.back()` 을 부른다.
직접 상태만 바꾸면 쌓아둔 이력이 남아 뒤로가기를 두 번 눌러야 앱이 나가진다.
