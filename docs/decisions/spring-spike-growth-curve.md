# 성장 곡선을 봄학기형으로 바꾼다 — 회복이 아니라 3월 스파이크 뒤 하강

**결정** — [Q4] 의 "실패 → 저점 → 회복 → 성장" 곡선을 버리고
**"저점 2개월 → 3월 봄학기 스파이크 → 서서히 감소"** 로 바꾼다.

| 국면 | 기간 | 가입 비중 | 활동 배수 |
|---|---|---|---|
| launch_spike | 2025-09 | 0.35 | 1.00 |
| decline | 2025-10~12 | 0.15 | 0.45 |
| **trough** | **2026-01~02** | 0.05 | 0.18 |
| **spring_spike** | **2026-03** | **0.20** | 0.80 |
| slow_fade_1 | 2026-04~05 | 0.15 | 0.60 |
| slow_fade_2 | 2026-06~07 | 0.10 | 0.42 |

**이유** — **학교 기반 서비스이기 때문이다.** 신학기에 확 들어왔다가 학기가
굴러가면서 관심이 식는 것이 학사 일정과 맞는다. 옛 곡선은 뒤로 갈수록
우상향(회복 → 성장)인데, 그건 계절과 무관하게 성장하는 서비스의 모양이다.

저점을 1월 한 달에서 **1~2월 두 달**로 늘린 것도 같은 이유다 — 겨울방학이
2월 초까지 이어지고 신학기 전까지는 바닥이 유지된다.

3월 스파이크는 9월(0.35)의 **57% 규모**로 잡았다. 두 번째 신학기지만
첫 출시만큼 몰리지는 않는다.

**대안** — 3월을 0.25 로 더 키우는 안을 제시했으나 0.20 을 골랐다.
9월의 71% 는 "두 번째 스파이크"라기에 너무 크다.

**영향**

- 실측이 설정과 **최대 0.5%p** 안에서 맞았다
  (34.8 / 14.5 / 5.1 / 20.0 / 15.2 / 10.3).
- MAU 가 9월 6,606 → 2월 저점 1,049 → 3월 4,328 → 7월 1,779 로 흐른다.
- **신규 유입의 정점과 활동량의 정점이 어긋난다** — 10월 세션(119,620)이
  9월(114,654)보다 많다. 9월 가입자가 10월에도 활동하기 때문이며 실제
  서비스에서도 흔한 현상이다. 결함이 아니다.
- 곡선 자체를 거는 방식은 [[growth-curve-two-channels]] 그대로다.
- ⚠️ **저점 대비 회복 MAU 가 2.18배**로 목표(2.5배)에 못 미친다. 모양은 맞고
  진폭이 작다.

## 이어지는 결정
- [[growth-curve-two-channels|성장 곡선은 가입과 활동 두 갈래로 건다 — 그리고 국면이 안 겹치면 끈다]]
  — 앞은 곡선을 **어떻게 거는가**(가입·활동 두 갈래), 뒤는 곡선의 **모양**을 정한다
- [[reactivation-cohort|휴면했다 돌아오는 유저를 만든다 — 3월에 몰리되 다른 달에도 있게]]
  — 둘 다 봄학기(3월)에 무게를 싣는다 — 신규 유입과 복귀가 같은 달에 겹친다
- [[school-sequential-adoption|학교를 순차로 열고, 학급 수를 정원에서 유도한다]]
  — 가입일을 먼저 뽑고 학교를 나중에 고르는 순서가 **성장 곡선을 보존한다**
