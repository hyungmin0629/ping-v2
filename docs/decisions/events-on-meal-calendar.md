# 학사일정을 급식 달력에 얹는다 — 따로 만들지 않고

**결정** — 학사일정을 별도 화면으로 만들지 않고 **급식 달력에 함께** 넣었다.
날짜 칸 아래 점이 그날 일정이고, 달력 아래에 그 달 일정이 통째로 나온다.

**이유** — 둘이 서로를 설명한다. 급식이 없는 날은 대개 방학이거나 휴업일인데,
급식 달력만 있으면 그 칸은 그냥 **회색으로 비어 있다.** 왜 비었는지가 같은
화면에 있어야 답이 된다. 따로 두면 "급식이 없네" → 다른 화면 → "아 방학이구나"를
이용자가 직접 이어야 한다.

**대안** — 홈에 토글을 하나 더. 기각. 홈 화면이 이미 길고, 두 화면 모두
같은 월 이동을 각자 갖게 된다.

**영향**
- 급식이 없어도 일정이 있으면 **날짜를 누를 수 있게** 바꿨다. 원래는 급식이
  있는 날만 눌렸는데, 정작 궁금한 날(방학·시험)에 급식이 없다.
- 점은 세 개까지만 찍는다. 그 이상은 칸을 넘고, 세어봐야 알 수 없다.
- 달 전체 목록을 항상 띄운다. 일정이 있는 날은 한 달에 열흘 남짓이라,
  눌러가며 찾게 두면 못 찾는다.
- 컴포넌트 이름을 `MealCalendar` → `SchoolCalendar` 로 바꿨다.
