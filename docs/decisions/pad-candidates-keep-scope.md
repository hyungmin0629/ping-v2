# 후보가 모자라면 스코프를 낮추지 않고 다른 친구로 채운다

**결정** — 스코프 안에서 후보 4명을 못 채우면, **스코프는 그대로 두고 친구 중
다른 사람으로 빈 자리를 채운다.** 채운 인원 수는 `vote_item.padded_count` 에
남기고, 화면에도 "이 범위의 친구가 모자라 다른 친구 N명이 후보에 들어갔습니다"
라고 밝힌다. 친구 전체로도 4명이 안 되면 그 질문은 내지 않는다.

**이유** — 하루 전 결정(스코프 하향)은 **모두가 같은 학교를 쓴다**는 전제 위에
있었다. 실제 학교 목록이 들어오면서 이용자가 여러 학교로 흩어지면, CLASS·SCHOOL
질문이 전부 GLOBAL 로 내려가 세 스코프를 나눈 의미가 사라진다.
채우는 방식은 스코프를 지키면서 질문을 살린다.

**대안** — 후보를 3명만 보여주기. 기각. 선택지 수가 들쭉날쭉하면 비교가 안 되고,
"4명 중 1명"이라는 전제로 만든 분석이 흔들린다.

**영향**
- 정합성 검사 두 개를 고쳤다. "CLASS 스코프에 타반 후보"는 이제 결함이 아니다.
  **"채운 수보다 타반 후보가 많다"** 를 결함으로 본다. 규칙대로 채운 것과
  규칙을 어긴 것을 구분할 수 있어야 하기 때문이다.
- `padded_count` 로 "친구 구성이 얼마나 편중돼 있나"를 셀 수 있다.
  같은 반 친구가 없을수록 이 값이 커진다.
- `effective_scope()` 함수는 지웠다. 남겨두면 어느 규칙이 진짜인지 헷갈린다.
- ⚠️ 이 값이 큰 투표는 "우리 반에서"라는 질문에 다른 반 사람이 섞인 결과다.
  분석할 때 `padded_count = 0` 인 것만 보는 편이 정확한 지표가 되는 경우가 있다.
