# 잔존 구간에 30~89일을 새로 넣는다 — v1 실측에서 일부러 벗어난다

**결정** — `retention` 에 **`within_quarter`(30~89일)** 구간을 신설하고
나머지 비율을 조금씩 덜어 재배분한다. `long_term` 의 하한도 30일 → 90일로 올린다.

| 구간 | v1 실측 | 바꾼 뒤 |
|---|---|---|
| no_activity | 4.1% | 4.1% |
| same_day_only | 28.4% | 26.0% |
| within_week | 35.5% | 32.0% |
| within_month | 27.8% | 24.0% |
| **within_quarter** | — | **10.0%** |
| long_term | 4.2% | 3.9% |

**이유** — 실측대로 두면 `within_month`(최대 29일) 위가 **곧바로**
`long_term` 이라 "한 달과 장기 사이"가 비어 있다. 12개월 코호트에서
그것이 **절벽**으로 나타났다.

| 2025-09 코호트 | M1 | M2 | 낙차 |
|---|---|---|---|
| v1 (구간 없음) | 26.5% | **3.9%** | 6.8배 |
| v2 (구간 신설) | 33.5% | **11.8%** | 2.8배 |

실제 서비스의 잔존 곡선은 완만하게 휘는데, 절벽이 있으면 **잔존 곡선의
모양 자체를 분석 대상으로 삼을 수 없다.**

**⚠️ 이것은 v1 실측 비율에서 의도적으로 벗어나는 유일한 항목이다.**
다른 값들은 "근거 없이 바꾸지 말 것"이 원칙이지만, 여기서는 실측을 그대로
쓰는 것이 **분석 가능성을 해친다**고 판단했다. 실측 4.1/28.4/35.5/27.8/4.2 는
1개월 관측 창에서 나온 값이라, 12개월 곡선의 중간을 설명할 재료가 애초에 없다.

**대안** — `long_term` 의 상한(30일~기간 끝)을 그대로 두고 비율만 올리는 안을
기각했다. 그러면 30일과 360일이 같은 구간에 섞여 활동 강도가 뭉개진다.

**영향**

- `voting.sessions_per_month_by_tier` 에 `within_quarter: [50, 110]` 을 넣었다
  (long_term 100~200 과 within_month 25~70 사이).
- 중간 활동층이 두꺼워져 **총 행수가 1억 4,126만 → 1억 8,826만(+33%)** 이 됐다.
- 코호트 낙차가 2.8배로 완만해졌다.
- 관련 — [[activity-by-retention-tier]] 가 구간별 활동 강도를 정한 결정이고,
  이 노드는 **구간 자체를 늘린** 것이다.

## 이어지는 결정
- [[activity-by-retention-tier|활동 강도는 잔존 구간마다 다르다]]
  — 앞은 구간을 **늘리고**, 뒤는 구간마다 활동 강도를 **정한다**
- [[user-personas|페르소나는 분류가 아니라 생성 편의다]]
  — 둘 다 v1 실측을 그대로 쓰지 않는다 — 분석 가능성을 위해 의도적으로 흐리거나 늘렸다
