# 같은 반 친구는 비율이 아니라 **수**가 기준이다 — 4명이 있어야 투표가 된다

**결정** — 학급 정원을 키우고(`students_per_class` 14~22 → **20~32**, 절대
상한 **35**), 같은 반에서 친구를 고르는 비율도 올린다(`same_class_ratio`
0.25 → **0.42**). 목표는 **"같은 반 친구가 3명 이하인 유저를 15% 아래로"** 다.

**이유** — CLASS 스코프 투표는 같은 반 친구가 **4명** 있어야 성립한다.
모자라면 GLOBAL 로 물러선다. 그러니 기준은 비율(14.1%)이 아니라 **수**다.

| 같은 반 친구 | v3 | v4 |
|---|---|---|
| 0명 | 3.4% | 3.4% |
| 1~3명 | 22.3% | **12.4%** |
| 4~5명 | 26.0% | 12.6% |
| 6~9명 | 33.6% | 33.7% |
| 10명+ | 14.6% | **37.9%** |
| **CLASS 투표 불가(0~3명)** | **25.7%** | **15.9%** |

CLASS 스코프 비중도 30.6% → **33.5%** 로 회복됐다(설정 35%).

## ⚠️ 학급을 키우는 것만으로는 안 됐다

`students_per_class` 를 14~22 → 20~32 로 올려 학급을 키웠더니 같은 반 친구
0~3명이 오히려 **25.7% → 26.9%** 로 늘었다.

`same_class_ratio` 는 **뽑는 비율**이라, 풀이 커져도 뽑는 횟수는 그대로다.
친구가 10명인 사람은 여전히 같은 반에서 2.5회만 뽑는다. **풀 크기와 뽑는
비율을 함께 올려야** 수가 늘어난다.

## 학급 정원 상한 35명

인기도가 학급 안 순위로 정해지므로(`popularity.scope: class`) 반이 커질수록
쏠림이 커진다. 정원 975명 학교의 한 반이 **77명**이 됐을 때 실제로 상위 10%
점유가 44% → 51% 로 뛰었다([[school-sequential-adoption]]).

학급 수를 `정원 ÷ 평균` 으로 유도하되, **상한으로 나눈 값을 하한**으로 둬서
분포의 위쪽도 35명을 넘지 않게 했다.

**대안** — `same_class_ratio` 만 올리는 안을 기각했다. 학급이 15명이면
같은 반 후보가 14명뿐이라, 비율을 올려도 금방 "이미 친구"가 되어 실패한다.

⚠️ **실측 23.7% 에서 의도적으로 벗어난 값이다.** [[retention-quarter-tier]] 와
같은 성격의 판단 — 실측을 그대로 쓰면 **분석이 성립하지 않는** 경우다.

**영향**

- 학급 수가 학교 정원에서 나오므로 학급당 인원이 20~32명(상한 35)으로 유지된다.
- 같은 반 친구 10명 이상인 유저가 14.6% → 37.9% 로 늘었다. "같은 반이
  촘촘한 학교"라는 상태가 데이터에 생겼다.

## 이어지는 결정
- [[pad-candidates-keep-scope|후보가 모자라면 스코프를 낮추지 않고 다른 친구로 채운다]]
  — 같은 반 후보가 4명이 안 될 때 무엇을 하는가 — 채우거나(앞), 애초에 모자라지 않게 하거나(뒤)
- [[retention-quarter-tier|잔존 구간에 30~89일을 새로 넣는다 — v1 실측에서 일부러 벗어난다]]
  — 둘 다 **실측을 그대로 쓰면 분석이 성립하지 않아** 의도적으로 벗어난 값이다
- [[school-sequential-adoption|학교를 순차로 열고, 학급 수를 정원에서 유도한다]]
